# Further Reading

## Official Documentation

- **[Quickshell Documentation](https://quickshell.org/docs/)** — The official reference for all Quickshell types, services, and configuration
- **[Quickshell QML Language Guide](https://quickshell.org/docs/guide/qml-language)** — Essential reading for understanding QML syntax and semantics
- **[Quickshell Type Reference](https://quickshell.org/docs/v0.3.0/types/)** — Complete API reference for all QML types

## Qt and QML Resources

- **[Qt 6 QML Reference](https://doc.qt.io/qt-6/qmlreference.html)** — The official Qt QML language reference
- **[QML Object Attributes](https://doc.qt.io/qt-6/qtqml-syntax-objectattributes.html)** — Properties, signals, methods, and attached objects
- **[Property Binding](https://doc.qt.io/qt-6/qtqml-syntax-propertybinding.html)** — How QML's reactive binding system works
- **[Qt Quick Performance](https://doc.qt.io/qt-6/qtquick-performance.html)** — Optimization techniques for QML applications
- **[QML Debugging](https://doc.qt.io/qt-6/qtquick-debugging.html)** — Debugging QML with the QML Inspector and profiler

## Wayland Protocols

- **[Wayland Explorer](https://wayland.app/protocols/)** — Browse all Wayland protocols with documentation
- **[wlr-layer-shell-unstable-v1](https://wayland.app/protocols/wlr-layer-shell-unstable-v1)** — The protocol that powers shell surfaces (panels, popups)
- **[ext-session-lock-v1](https://wayland.app/protocols/ext-session-lock-v1)** — Wayland lock screen protocol
- **[wlr-foreign-toplevel-management](https://wayland.app/protocols/wlr-foreign-toplevel-management-unstable-v1)** — Window enumeration and management

## Linux Desktop Integration

- **[freedesktop.org Specifications](https://specifications.freedesktop.org/)** — Standards for the Linux desktop
- **[D-Bus Tutorial](https://dbus.freedesktop.org/doc/dbus-tutorial.html)** — Understanding the D-Bus message bus
- **[MPRIS Specification](https://specifications.freedesktop.org/mpris-spec/latest/)** — Media player remote control interface
- **[Notification Specification](https://specifications.freedesktop.org/notification-spec/latest/)** — Desktop notification protocol
- **[Autostart Specification](https://specifications.freedesktop.org/autostart-spec/latest/)** — Desktop file autostart standard

## Compositor Documentation

- **[Hyprland Wiki/IPC](https://wiki.hyprland.org/IPC/)** — Hyprland's inter-process communication
- **[Sway Wiki](https://github.com/swaywm/sway/wiki)** — Sway window manager community wiki
- **[wlroots Documentation](https://gitlab.freedesktop.org/wlroots/wlroots/-/tree/master/docs)** — The wlroots compositor library

## Community Resources

- **[Quickshell GitHub](https://github.com/wardvis/Quickshell)** — Source code, issues, and pull requests
- **[r/unixporn](https://reddit.com/r/unixporn)** — Linux customization showcase (search "quickshell")
- **[Arch Wiki: Quickshell](https://wiki.archlinux.org/title/Quickshell)** — Arch Linux community documentation

## Related Projects

- **[Waybar](https://github.com/Alexays/Waybar)** — A popular Wayland bar (C++)
- **[swaylock-effects](https://github.com/mortie/swaylock-effects)** — Feature-rich lock screen
- **[eww](https://github.com/elkowar/eww)** — Elkowar's wacky widgets (Yuck-based)
